## Known gaps in this manifest

| Gap | Detail |
|---|---|
| `EVIDENCE_GAP` | **Original per-file byte streams of the review submission are not included.** Each round's prompt was assembled from the working-tree files and the assembled prompt was fed to the reviewer; the prompts themselves (`round3N-prompt.txt`, ~890 KB each) remain in `/tmp` and are not committed. The SHA256 values above therefore let a reader verify *internal consistency* of the committed files, not that these bytes are the bytes the reviewer saw. |
| `EVIDENCE_GAP` | **No proposed artifact was ever compiled or exercised.** No sandbox profile, no Seatbelt rule, no network proxy, and no approval channel were run. Every mechanism in these documents is a design proposal. |
| `EVIDENCE_GAP` | **The prior empirical evaluation is not included.** Upstream source observations (spawn inventory, permission-model behaviour) were made in an earlier session and are cited by `OSS_RESEARCH_EVIDENCE.md`, but the underlying transcripts are not part of this branch. |

| `MISSING_ARTIFACT` | Compile spike and call-graph output — not produced. `IMPLEMENTATION_PLAN.md` P0 criterion (1) specifies them as work to be done, not work already done. |
| `MISSING_ARTIFACT` | Per-round review prompts (`round{29..33}-prompt.txt`) — left in `/tmp/codex-review/`, not committed for size. The assembler that builds them from committed parts IS committed (`research/scripts/assemble33.py`), so they are reproducible. |

## How to reproduce a review round

```
python3 research/scripts/assemble33.py          # rebuilds round33-prompt.txt, asserts all 10 parts present
cd <repo> && codex exec --sandbox read-only --ephemeral -C <repo> - < /tmp/codex-review/round33-prompt.txt
python3 research/verification/verify.py          # lexical consistency checks; RESULT: 0 FAILURE(S)
python3 research/scripts/nc33.py                 # negative control: proves §5b can fail
```

**`verify.py` returning 0 failures is not evidence that the security boundary
holds.** It checks selected lexical properties across six documents. It cannot
adjudicate whether the design is correct, and rounds 29-33 each found defects it
did not catch.
